# DrawEm26 ⚽ (OUTDATED)

**DrawEm26** is a World Cup draw simulator built ahead of the **2026 World Cup** group stage draws. It lets you randomly draw teams into groups and even simulate group positions to automatically generate the Round of 32 knockout stage.

## 🚀 Features
- 🎲 Random team draw into groups  
- 🏆 Randomized group positions  
- 🔄 Automatic Round of 32 bracket generation  
- 📱 Fully responsive design  

## 🛠️ Built With
- React JS  
- CSS  

## 📌 About
This is one of my mini-projects created to improve my overall frontend development skills while building something fun and football-related!
